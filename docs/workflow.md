# Workflow: Жизненный цикл задачи

| # | Шаг | Кто | Вход | Выход |
|---|-----|-----|------|-------|
| 1 | Изучение | оркестратор | задание + твой SPEC | пересказ задачи своими словами |
| — | **Ты: согласование** | — | пересказ | ок / правка SPEC |
| 2 | Написание | кодер | SPEC | код |
| 3 | Компиляция | команда | — | ошибки → кодеру, до 2 раз, потом стоп |
| 4 | Тесты | тестировщик | SPEC (+ API: реши) | тесты |
| 5 | Запуск тестов | команда | — | красные → кодеру, до 2 раз, потом стоп |
| 6 | Ревью | ревьюер | SPEC + код + результат тестов | отчёт |
| — | **Ты: решение** | — | отчёт ревьюера | ок / правки |
| 7 | Коммит и PR | оркестратор | твой ок | PR |

## Пояснения по шагам

1. **Изучение** — оркестратор читает задание и SPEC, формулирует пересказ задачи своими словами.
   - **Твоё участие:** согласование пересказа → `ок` либо правка SPEC.
2. **Написание** — кодер пишет код по SPEC.
3. **Компиляция** — команда собирает проект. При ошибках они уходят кодеру (до 2 итераций), затем стоп.
4. **Тесты** — тестировщик пишет тесты по SPEC (если нужен API — решает сам).
5. **Запуск тестов** — команда гоняет тесты. Красные → кодеру (до 2 итераций), затем стоп.
6. **Ревью** — ревьюер проверяет SPEC + код + результаты тестов, выдаёт отчёт.
   - **Твоё участие:** решение по отчёту → `ок` либо правки.
7. **Коммит и PR** — оркестратор коммитит и открывает PR после твоего `ок`.

## Точки контроля (твоё участие)

- После шага **1** — согласование пересказа.
- После шага **6** — решение по отчёту ревьюера.

## Лимиты повторов

- **Компиляция:** до 2 раз, потом стоп.
- **Тесты:** до 2 раз, потом стоп.
